To run the backend consistently in local/preview:

- Use the helper script:
  bash note-keeper-47299-47308/notes_backend/.init/start.sh

If needed, make it executable once:
  chmod +x note-keeper-47299-47308/notes_backend/.init/start.sh

Environment variables:
- HOST (default 0.0.0.0)
- PORT (default 3000)
- LOG_LEVEL (default info)
- RELOAD_FLAG (set to --reload for development)
